# 验证清单

> 状态：当前参考（验证流程）｜最后同步：2026-11-14

## 1. 每次提交前

```text
dart tool/check_docs.dart
cd app
flutter analyze
flutter test
cd ..
```

要求：check_docs 0 issue；analyze No issues；test 全过。实际测试数量只记录在
`01-规范/项目数据.md`，不在本文件复制。

## 2. 每个维护批次/阶段结束

```text
dart tool/verify.dart --build
```

`tool/verify.dart` 串起 check_docs + analyze + test；`--build` 再跑
`cd app && flutter build apk --debug`。构建前确认：

- `app/assets/fonts/HarmonyOS_Sans_SC_Regular.ttf` 存在（不入库）。
- `app/android/local.properties` 存在（Flutter 生成）。
- 没有模型/词典/UniDic/密钥被加入 Git 跟踪。

## 3. 设备端集成测试

命令与 adb 推数据步骤见 `05-参考/开发环境与构建.md`。6 个套件：

- `app/integration_test/mecab_android_test.dart`
- `app/integration_test/mdict_android_test.dart`
- `app/integration_test/mdict_compat_android_test.dart`
- `app/integration_test/mdict_audio_android_test.dart`
- `app/integration_test/ocr_android_test.dart`
- `app/integration_test/ocr_real_images_android_test.dart`

涉及 OCR/UniDic/MDict 的 M1 批次不得只跑单元测试；真机/模拟器结果记录到
`01-规范/项目数据.md`，未跑就写“未验收”，不要写成已验证。

## 4. 发布前

- 替换 debug keystore（`app/android/app/build.gradle.kts` TODO；R-DEV-05）。
- 版本号：`app/pubspec.yaml` 的 `version:` 唯一来源；构建产物
  versionName/versionCode 必须一致。
- 确认模型/字体/词典/API Key 不在仓库。
- 检查 `app/assets/models/manifest.json` 的 URL/SHA-256 与许可字段。
- 更新 `01-规范/项目数据.md` 的 `last_verified`/commit 锚点。
- 不把真实 provider/API Key、secure storage、arm64 Agent、真机视觉写成已验证。

## 5. 冒烟清单（手动）

- 主页 5 入口：拍照识别、查句子、查单词、历史记录、词典助手。
- 文本阅读：分词、注音开关、字号、复制、点击查词。
- 照片集：拍照/相册/多选、横排/竖排/自动、旋转、保存语料。
- 查词：词典筛选、完全/前方/后方/增量、多个结果“查看全部”。
- 语料：列表/详情/清空/删除/复制。
- 设置：词典管理、OCR 模型页（名称/许可/备注）、UniDic、存储权限。
- Agent：离线打开、未配置 provider 时不联网、历史/档案入口。
- 升级/冷启动：不因文档或资源迁移丢数据。
