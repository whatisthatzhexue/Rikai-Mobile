# 版本与阶段命名规范

> 状态：当前权威（命名规范）｜最后同步：2026-11-11

Review目标 的原话是“Wave 4 P6.7 P6.8 还有 P0 P1 P2 Phase 1 Phase 2 这样，
非常反常理不方便阅读”。这不是个别笔误，而是**六个正交维度共用 `P`/`Phase`/`Wave`
前缀**造成的。

## 1. 迁移前盘点（2026-11-10）

| 标签族 | 出现次数 | 实际含义 | 冲突 |
|---|---:|---|---|
| `Phase N` | 399 | 产品阶段 0–7 | `P0/P1/P2`、`Phase 1a–4` |
| `阶段 N` | 0 | 中文产品阶段 | 文档几乎不用中文阶段名 |
| `P6.x` / `P7.x` | 458 / 54 | 阶段 6/7 工作包 | 与 `Phase 6/7` 写法不统一 |
| `P0/P1/P2` | 45 | 优先级/分诊 | 与产品阶段、工作包视觉冲突 |
| `Wave N` | 146 | 2026-10-31 设备反馈波次 | 在其他文档裸写时像产品阶段 |
| `Phase 1a–d` | 26 | Agent 重构步骤 | 与产品阶段 `Phase 1` 冲突 |
| `Phase -1/0/1` | 1（Review目标） | 维护期 | 与产品阶段同名 |
| `P6.8` / `P6.8-lite` | 41 / 18 | 完整规划 / 当前收窄范围 | 裸写 `P6.8` 指代不明 |
| `P7` / `P7-lite` | 54 / 18 | 完整规划 / 当前收窄范围 | 裸写 `P7` 指代不明 |

统计范围：`CLAUDE.md`、`README.md`、`docs/**/*.md`、`docs/**/*.txt`。

## 2. 唯一写法

| 维度 | 唯一写法 | 禁止/别名 | 示例 |
|---|---|---|---|
| 产品阶段 | 中文正文 `阶段 N`；英文文档 `Phase N` | `Phase` 与工作包混写 | `阶段 6`、`Phase 6`（英文） |
| 阶段 6/7 工作包 | `P6.x`、`P7.x`、`P6.7-1` | `Phase 6.7`、`阶段 6.7` | `P6.7-2`、`P7.0` |
| 设备反馈波次 | 仅设备反馈文档用 `Wave N`；中文其他文档 `反馈波次 N`；英文 `feedback wave N` | 其他文档裸写 `Wave N` | `反馈波次 4` |
| 优先级 | `优先级 高/中/低` 或 `批次 A/B/C` | `P0/P1/P2` | `优先级 高` |
| 维护阶段 | `M-1/M0/M1` | `Phase -1/0/1` | `M0 文档结构` |
| Agent 重构 | `R1a–R4` | `Phase 1a–4` | `R1a 档案编译器` |
| 范围 | 完整写 `P6.8（完整）`/`P7（完整）`；当前写 `P6.8-lite`/`P7-lite` | 裸写 `P6.8`/`P7` 指当前实施 | `P6.8-lite` |

`Phase` 只作英文别名，等价于中文 `阶段`；`P6.x`/`P7.x` 只表示工作包，不是产品阶段。

## 3. 旧→新映射

| 旧写法 | 新写法 | 适用范围 |
|---|---|---|
| `Phase 0`–`Phase 5` | `阶段 0`–`阶段 5` | 中文正文的产品阶段 |
| `Phase 3.5/4.5` | `阶段 3.5/4.5` | 产品子阶段 |
| `Phase 6`（工作包语境） | `阶段 6` + `P6.x` | 产品阶段与工作包分开写 |
| `P0/P1/P2`（优先级） | `优先级 高/中/低` 或 `批次 A/B/C` | 分诊/优先级 |
| `Phase 1a`–`Phase 1b` | `R1a`–`R1b` | Agent 重构步骤 |
| `Phase -1/0/1`（维护） | `M-1/M0/M1` | 维护期 |
| `Wave 1`–`Wave 4` | 设备反馈文档内保留；其他中文文档 `反馈波次 N`；英文 `feedback wave N` | 设备反馈 |
| `P6.8`（指当前实施） | `P6.8-lite` | 范围 |
| `P7`（指当前实施） | `P7-lite` | 范围 |
| `P6.8`/`P7`（指完整规划） | `P6.8（完整）`/`P7（完整）` | 范围 |

## 4. 执行规则

- 只改标签，不改数值、结论、实现状态。
- 当前中文文档（`01/02/03/05/07` + `CLAUDE.md`）执行映射；`P6.x`/`P7.x` 保留。
- 当前英文文档（`README.md`、ADR、英文参考）保留 `Phase N`；`Phase 1a–4` 改 `R1a–R4`；
  `README.md` 的 `Wave N` 改 `feedback wave N`。
- 历史文档（`04-历史`）按 R-DOC-05 保留原文，只加“历史原文：Phase=阶段，
  Wave=设备反馈波次，P0/P1/P2=旧优先级”横幅。
- `Review目标.txt` 是用户手写来源，不修改。
- 无法在不改变语义的前提下替换的，登记到本文件“例外”，不要强行改写。

## 5. 检查规则

`tool/check_docs.dart` 对当前中文文档检查：

- 禁止 `Phase [0-9]`、`Phase 1[a-d]`、`P0/P1/P2`；
- 非设备反馈文档禁止 `Wave [0-9]`；
- `P6.8` 必须带 `-lite` 或 `（完整）`；`P7` 必须带 `.x`、`-lite` 或 `（完整）`；
- 历史文档与 `版本命名.md` 的示例表豁免。
