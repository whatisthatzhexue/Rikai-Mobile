## 一、MDict 词典一键导入

**目标**：用户选择一个词典总目录，应用自动发现其中（含所有子目录）的 MDict 词典，并一次性加入词典库，无需逐个选择文件。

**入口**：设置 → 词典管理 →「从文件夹导入」。

**流程**：
1. 点击后打开系统目录选择器，用户选择词典总目录。
2. 应用递归扫描该目录及所有子目录，收集 `.mdx` 文件（扩展名不区分大小写）。
3. 展示扫描结果：每个 `.mdx` 一行，包含：
   - 词典名（优先读取 MDX 标题，失败时回退文件名）
   - 所在文件夹
   - 文件大小
   - 状态：可导入 / 已存在 / 不支持（不展示英文原始异常）
   - 不再显示 `.mdd` / `.css` 英文数量尾注。
4. 默认全选“可导入”项，用户可取消个别勾选；主按钮为「导入所选（N）」。
5. 导入过程显示总进度（当前第 N/M 个、当前阶段），支持取消；单个词典失败不中断整体。
6. 完成后直接刷新并返回词典管理页，不弹“导入结果”对话框；失败/取消仅用非阻塞 SnackBar 报告数量。

**规则**：
- 一个 `.mdx` 对应一个词典；同目录下的同名 `.mdd` 和目录内 `.css` 自动关联（沿用现有规则）。
- 同一文件夹内存在多个 `.mdx` 时，分别导入，不合并。
- 词典库中已存在的路径标记为“已存在”，默认跳过，避免重复。
- 导入前预检：不支持 LZO、记录块加密、checksum 或 v3 的文件，在列表中直接标记为“不支持”并说明原因，不阻塞其他词典。
- 原地读取，不复制 `.mdx`/`.mdd`，不向用户目录写入任何文件。
- 无“所有文件访问”权限且目录不可读时，引导用户授权，或提示将词典放入应用外部私有目录。
- 扫描与校验在后台 isolate 执行，避免阻塞 UI；按真实路径去重，跳过符号链接循环。

**验收**：
- 一个包含 10 个词典（其中 1 个损坏）的目录，可一次导入 9 个，损坏项标记为“不支持”。
- 已导入的词典不会重复出现在可导入列表中。
- 扫描含 1000 个文件的目录时页面不卡顿，且可取消。

## 二、阅读页查词与键盘行为

**问题**：输入框获得焦点、软键盘展开时，点击词条打开查词弹层；之后点击弹层外区域（包括键盘位置）想关闭弹层，键盘反而重新弹出。

**期望行为**：
- 分词完成后进入“阅读态”：键盘默认收起，输入框不自动获得焦点。
- 用户点击任意词条时：先收起键盘、清除输入框焦点，再打开查词弹层。
- 关闭弹层（下滑、上滑、点击遮罩、返回键）后：键盘保持收起，输入框不获得焦点，阅读位置不变。
- 只有用户明确点击输入框或“编辑”入口时，键盘才弹出。
- 点击阅读区空白、结果区或工具栏空白，均不得触发键盘。

**实现要点**：
- 词条点击回调中先执行 `FocusManager.instance.primaryFocus?.unfocus()`，再展示弹层。
- 弹层使用独立的 `FocusScope`，遮罩点击不能把焦点交还给下层 `TextField`。
- 弹层关闭后再次 `unfocus()`，不要在页面返回后恢复焦点。
- 检查并移除输入框或页面上任何会导致自动重新聚焦的行为（如 `autofocus`、错误的 `onTapOutside`）。
- 回归测试：键盘展开 → 点击词条 → 点击遮罩关闭 → 断言键盘高度为 0，焦点不在输入框。

## 三、OCR 模型页

**文案**：
- 删除内部说明：“模型不随应用分发。下载后保存在应用外部私有目录，完全离线运行。”
- 如仍需提示，改为面向用户的一句话：“OCR 模型需单独下载，下载完成后可离线使用。”
- 不展示 `RIKAI_OCR_MODELS_DIR` 等开发配置。

**模型目录**：
- 在模型页展示当前模型目录，使用 16sp 纯文本（不使用输入框或卡片），允许长按复制。
- 提供「更改目录」按钮，打开系统目录选择器。
- 校验新目录：可读、可写、剩余空间足够；保存到设置并立即刷新模型状态。
- 切换目录时提供两种方式：
  - 默认「迁移现有模型」：移动或复制到新目录，显示进度；
  - 「仅切换目录」：保留原目录文件，之后在新目录重新下载或导入。
- 目录不可用（被删除、SD 卡移除、权限丢失）时，显示“模型目录不可用”及「重新选择」入口，不清空其他设置，不崩溃。
- 显示模型占用空间（如“已安装 20.5 MB”），帮助用户判断存储成本。

**验收**：
- 首次进入不出现任何测试路径或内部说明。
- 目录切换后，模型状态、下载、导入、删除均针对新目录生效。
- 目录失效时页面可恢复，不需要清除应用数据。

## 四、MDict 与 UniDic 导入界面统一

两个入口使用同一套布局和组件：

1. 分区标题；
2. 路径输入框（空值时显示 `hintText`，**不是默认值**）；
3. 「浏览」按钮（目录选择器）；
4. 校验状态或扫描结果；
5. 主操作按钮（校验 / 保存 / 导入）；
6. 14sp 说明文字，完整换行，不使用省略号。

**占位符**：
- MDict：「请选择词典所在文件夹」
- UniDic：「请选择 UniDic 词典文件夹」

**其他规则**：
- 移除所有测试或示例默认路径（如 `/sdcard/Download/...`）；空值即“未设置”。
- MDict 浏览后列出发现的 `.mdx` 供勾选；UniDic 浏览后校验 5 个必需文件并显示缺失项。
- 按钮层级统一：每屏最多一个主按钮，其余使用描边按钮或文本按钮。
- 不使用带边框的 Card/Container 包裹输入框、按钮和提示。

**验收**：
- 首次进入两个页面时都显示空输入框和中文占位符，不含任何实际路径。
- 两个页面的「浏览」按钮位置、样式和行为一致。

## 五、拍照识别页重构

### 5.1 页面流

```text
主页
└─ 拍照识别（实时相机页）
   ├─ 快门 / 相册导入 → 加入照片集
   ├─ 照片集（单张查看 + OCR 自动分词结果）
   │  ├─ 复制 / 字号与注音 / 点词查词
   │  ├─ 删除 / 保存当前照片
   │  └─ 多选 → 多选页（网格 + 批量操作）
   └─ 返回主页
```

打开照片集（或进入后台）时释放相机；返回相机页时重新启动预览。

### 5.2 拍照识别页（相机页）

- 顶栏保持深蓝色，标题「拍照识别」。
- 相机实时预览铺满顶栏以下的整个页面。
- 底部控制区悬浮在预览之上，并使用半透明遮罩保证可读性：
  - 居中：快门按钮；
  - 左侧：「导入照片」；
  - 右侧：「照片集」，带照片数量角标。
- 快门：拍摄一张照片并加入照片集，停留在相机页，支持连续拍摄。
- 导入照片：支持一次选择一张或多张；每张照片作为一个独立条目按选择顺序加入照片集，与快门拍摄的照片同权。
- 相机权限被拒绝：显示说明，提供「去授权」和「从相册导入」两个入口。
- 无相机硬件或相机启动失败：显示说明并保留相册导入。
- 生命周期：应用进入后台或打开照片集时暂停预览；返回时恢复；离开页面时释放相机资源。
- 页面固定竖屏；预览使用 `BoxFit.cover`，避免黑边和拉伸。

### 5.3 照片集页（单张查看）

从上到下：

1. **顶栏**：标题「照片集」，右侧依次为「复制」、字号/注音菜单、「多选」。
2. **照片区**（上部）：当前照片，`BoxFit.contain`。
   - 下边缘可拖拽调整照片区高度（默认 250、最小 120）；
   - 点击照片打开黑底全屏查看器，支持双指缩放与拖动；
   - 删除/保存不放在照片区，而是固定在整个画面左下/右下角。
3. **识别结果区**（中部）：可滚动。
   - 已配置 UniDic 时自动分词，按文本阅读页的 TokenChip 样式显示，可点词查词；
   - 未配置 UniDic 或分词失败时显示 OCR 原文和原因；
   - 状态：识别中（进度 + 取消）、识别成功、未识别到文字、识别失败（错误信息 + 重试）。
4. **识别模式**（偏下）：自动 / 横向 / 竖向。
   - 切换模式后立即对当前照片重新识别。
   - 竖向模式在 Phase 4 完成前显示为禁用，并提示“后续版本支持”。
5. **复制与字号**：标题栏「复制」始终可用（识别出文本后）；字号/注音菜单
   与文本阅读页共用（16/20/24/28、显示注音）。不再有“分析句子”按钮。
6. **页码区**（最下方）：`←  1/10  →`。
   - 点击箭头切换到上一张/下一张，页码同步更新；
   - 第一张时左箭头禁用，最后一张时右箭头禁用；
   - 切换到尚未识别（或缓存失效）的照片时自动触发识别。
7. **模型设置入口**：文本按钮「模型设置」，跳转现有设置中的 OCR 模型页；不在此页重复模型管理界面。
   - 返回时若模型文件发生变化，清除识别缓存并重新识别当前照片。

**识别规则**：
- 进入照片集时，若当前（首张）照片没有当前模式下的有效缓存，自动开始识别。
- 每张照片按“照片 + 模式 + 模型指纹”缓存结果；切换照片优先使用缓存。
- 切换模式使当前照片的对应缓存重新生成；模型变化使全部缓存失效。
- 识别任务同一时间只允许一个；切换照片或离开页面时取消旧任务，避免结果串页。

**删除当前照片**：
- 点击垃圾桶后弹出二次确认：「从照片集中删除这张照片？」
- 复选框「同时删除原文件」，**默认不勾选**。
  - 快门拍摄：原文件指本次会话保存的照片文件；
  - 相册导入：原文件指设备相册中的原照片（需要系统删除授权；无法删除时提示只能从照片集移除）。
- 删除后：若还有照片，显示相邻一张；若已无照片，返回相机页并清空照片集。

**保存到语料库**：
- 点击保存后弹出二次确认，说明将保存的内容：照片 + OCR 原文 + 分词结果 + 识别模式 + 时间。
- 成功后提示「已保存到语料库」。
- 语料库能力属于 Phase 5；在语料库存储实现前，此按钮隐藏或禁用并注明“后续版本支持”。

### 5.4 多选页

- 入口：照片集页右上角「多选」。
- 布局：网格并排展示照片缩略图，每张照片叠加 OCR 结果预览（最多 2–3 行，超出省略）。
- 尚未识别或缓存失效的照片显示「尚未识别」标记；进入多选页后按当前模式在后台顺序补识别，缩略图上显示进度，可取消。
- 每张照片带复选框；支持「全选 / 取消全选」，显示已选数量。
- 删除/保存不再放底部操作栏，而是与单张页共用画面左下/右下角的 52dp 圆形图标；
  保存为深蓝 `header` + 白图标。
- 批量删除需二次确认，同样提供「同时删除原文件」复选框，默认不勾选。
- 批量保存需二次确认，说明保存数量。
- 操作完成后刷新网格；全部删除后返回相机页。

### 5.5 会话与数据规则

- 照片集是本次拍摄会话的有序列表，每项包含：会话内 ID、本地文件路径、原始来源（相机/相册）、原文件引用（用于“同时删除原文件”）、OCR 缓存。
- 快门拍摄和相册导入的照片统一复制/规范化到应用私有的会话目录，避免依赖系统临时缓存。
- 会话在应用运行期间保留；退出拍照识别页后仍保留（便于再次打开照片集）。
- 应用重启后清空未保存到语料库的会话照片；已保存到语料库的照片由语料库管理。
- 删除会话照片时同步删除会话目录中的副本；勾选“同时删除原文件”时再尝试删除设备原照片。
- 所有识别在设备本地完成，不上传图片或文本。

### 5.6 工程约束

- 当前 `image_picker` 通过系统相机 Intent 取图，**新设计需要实时预览，必须引入 `camera` 插件并声明 `CAMERA` 权限**；权限请求失败要给出明确引导，不引入 `permission_handler`（项目已有兼容问题）。
- 相机页使用 `WidgetsBindingObserver` 处理前后台切换；打开照片集时 `dispose` 相机控制器，返回时重建。
- 相机页的遮罩、快门环等新视觉元素需先加入 `app_tokens.dart`，页面禁止硬编码颜色/尺寸。
- OCR 单任务串行；切换照片、切换模式、离开页面时取消旧任务，用请求 ID 丢弃过期回调。
- 图片方向由原生 EXIF 修正逻辑处理；导入照片与拍摄照片走同一识别入口。
- 识别最长可能约 10 秒/页，必须有进度和取消，不得阻塞相机恢复。
- Phase 4 前竖向模式禁用；Phase 5 前语料库保存隐藏/禁用。

### 5.7 验收标准

- 打开拍照识别页即可看到全屏相机预览，顶栏保持深蓝，底部三个控件不遮挡预览主体。
- 连续拍摄 3 张后打开照片集，首张照片自动识别并显示结果与 `1/3`。
- 点击右箭头切到第 2 张，页码变为 `2/3`，并对该照片自动识别。
- 切换识别模式会重新识别当前照片；从模型设置返回且模型变化时也会重新识别。
- OCR 完成后已配置 UniDic 时直接显示分词结果；点击词条弹出查词层。
- 未配置 UniDic 时仍显示 OCR 原文、允许复制与调整字号。
- 拖动照片区下边缘可改变高度；点击照片打开全屏缩放查看器。
- 删除当前照片默认不删除设备原图；勾选后才尝试删除原图。
- 多选页可批量删除/保存，未识别照片先显示“尚未识别”，补识别完成后显示文本预览。

## 六、已确认的假设

确认结果：1）一个 `.mdx` = 一个词典；2）照片集为应用会话级；3）按需识别 +
照片/模式/模型指纹缓存；4）原图删除为尽力而为，失败时只移除会话副本；
5）模型目录切换默认迁移，同时保留仅切换；6）竖向 Phase 4 前禁用，完整语料
管理 Phase 5，基础保存已提前实现。

1. **一个 `.mdx` 对应一个词典**；同一目录的 `.mdd`/`.css` 自动关联。若你希望“一个文件夹 = 一个词典”（即使含多个 `.mdx` 也合并），需要调整。
2. 照片集是**本次会话**的有序列表，退出拍照识别页后保留，应用重启后清空未保存项。
3. OCR 采用**按需识别 + 缓存**：进入照片集自动识别当前照片，切换照片时补识别；多选页后台补识别未缓存项，而不是一次性识别全部。
4. “同时删除原文件”对相册导入的照片需要系统级的相册删除授权；无法实现时退化为仅移除照片集副本，并明确提示用户。
5. 模型目录切换默认**迁移现有模型**，同时保留“仅切换目录”选项。
