# Rikai-Mobile 设计 Token 规范

> 版本 1.9 · 2026-10-29（Phase 4 竖向 MangaOCR、自动方向与 180° 校正）
> 状态：**强制规范**。所有现有与后续 UI（含 Phase 2+）必须遵循本文件；
> 功能设计与 UI 设计同步进行时以此为准。
>
> 实现：`lib/core/theme/app_tokens.dart`（token）与 `AppTheme.light()`
> （Material 3 主题）。页面中不得硬编码颜色、字号、间距、圆角。

## 1. 视觉方向

- **蓝 / 白**：白色内容面 + 浅灰蓝页面底色 + 品牌蓝交互色。
- **紧凑直观**：4pt 间距体系，常规控件高 40dp，列表与卡片低留白。
- **阅读优先**：正文清晰、层级克制；不使用的装饰性阴影和大面积渐变。
  阅读器的阅读面、结果区与输入/分词/复制工具区**均为白色**；工具区底边为
  1px `divider` **浅色细线**（类似查词搜索栏下方），与结果区自然分隔，
  不改变工具区底色、不形成厚重色块。阅读器内不使用灰色文字。
- **平面分层**：1px 边框代替阴影；卡片白底、圆角 12。
- **单一光源**：每屏一个主操作（品牌蓝实心按钮），其余操作用描边/文字按钮。
- 当前版本**只提供浅色主题**；深色主题不属于 v1 规范，后续如需加入必须先扩展
  token 表，不得在页面里临时反色。

  （近黑），振假名用品牌蓝 `primary`。
- 正文与背景对比度 ≥ 4.5:1；次要文字 ≥ 3:1。
- 不使用 Material 默认紫色、绿色系 seed 色；不使用随机的 `Colors.*`。
- 错误/成功同时配合图标或文字，不能只靠颜色表达。

## 3. 字体与字号

- 字体家族：**HarmonyOS Sans SC**，Regular（400）。
- 资源路径：`assets/fonts/HarmonyOS_Sans_SC_Regular.ttf`。
- **字体文件不入库**：由使用者自行从华为 HarmonyOS 设计资源下载，说明见
  `assets/fonts/README.md`。构建前必须放置到上述路径，否则 Flutter 构建失败。
- 当前仅提供 Regular。层级通过**字号 + 颜色 + 留白**建立，不依赖多种字重；
  后续若加入 Medium/Bold，必须同步更新 `pubspec.yaml`、`app_tokens.dart` 和本表。
- 用户可在左侧抽屉的“自定义字体”中切换 **HarmonyOS Sans（内置）** 与
  **系统默认**；默认是 HarmonyOS Sans。字体文件不入库，见第 9 节。

### 3.1 字号组合（72 / 48 / 36）

设计稿按 **3x** 标注；Flutter 逻辑字号为设计 px ÷ 3：

| Token | 设计稿 | Flutter | 行高 | 用途 |
|---|---:|---:|---:|---|
| `AppTypography.display` | 72px | **24sp** | 1.25 | 首页主标题、空状态标题、词条页大标题 |
| `AppTypography.headline` | 48px | **16sp** | 1.5 | 正文、列表标题、按钮、输入文字、Tab |
| `AppTypography.title` | 36px | **12sp** | 1.5 | 极短标签/时间；不用于正文、设置说明、帮助/著作权 |

补充组件字号（不改变 72/48/36 主阶梯）：

| Token | 值 | 用途 |
|---|---:|---|
| `AppTypography.helper` | **14sp** | 设置/表单提示、列表副标题、搜索结果摘要 |
| `AppTypography.sectionHeading` | **18sp** | 帮助/著作权等长文页的栏目标题 |
| `AppTypography.entryTitle` | **24sp** | 查词结果词条标题（16sp 的 1.5 倍） |
| `AppTypography.homeAction` | **32sp** | 主页功能按钮（居中；比首版 40sp 小 20%） |
| `AppTypography.ocrPreview` | **20sp** | 多选页缩略图内的 OCR 预览文字 |

> 注意：72/48/36 是 3x 设计稿标注，不是 Flutter 直接使用的 sp。移动端直接使用
> 72sp/48sp/36sp 会破坏布局，禁止。

- 标题/按钮使用 16sp 与语义色；24sp 用于页面级重点和查词结果词条。
- 正文不得低于 16sp；设置/表单的灰色提示统一 14sp，且必须允许换行，
  **禁止出现省略号或显示不全**。
- 12sp 只用于极短标签；不要用于设置说明、帮助/著作权正文或搜索结果。
- 默认 `letterSpacing: 0`；中文标签不使用负字距。

### 3.2 阅读区字号（内容例外）

阅读区正文是用户可调内容，不属于 UI chrome：

- 范围 14–30sp，默认 **20sp**（`AppTypography.readerDefault`）。
- 行高 1.6；振假名字号为主字号的 **55%**（`furiganaRatio`）。
- 标点/空白不显示注音。
- 阅读面、结果列表与输入/分词/复制工具区**均为 `surface` 白色**；工具区
  底边为 1px `divider` 浅色细线（对齐查词搜索栏下方的处理）。输入框
  `filled: false`，不额外铺白色块；工具区高度紧凑，白色底上只保留这条
  浅色收边，长文滚动时不得出现厚重色块分区。
- 内容词：蓝50背景 + 蓝700文字；功能词与标点：透明背景 + `textPrimary`
  （近黑）；振假名：品牌蓝 `primary`。**不得在阅读器内使用灰色文字**；
  以蓝色/黑色/字重建立层级，减少视觉刺激。

### 3.3 词典 WebView

- 词条正文：白色背景、`font-size: 16px`、`line-height: 1.7`、页面内边距 16px。
- 保留词典自带 CSS；图片 `max-width: 100%`。
- 应用外壳（AppBar、Tab）使用本 token；WebView 内容保持词典原貌。

## 5. 组件规范

### 布局原则（强制）
- **禁止组件套组件**：输入框、按钮和提示文本直接放在页面/分栏上，
  不要包在带边框的 Card/Container 里（UniDic 目录栏是反例，必须保持扁平）。
- 设置页采用白底扁平分区：分区标题 → 分隔线 → 控件；整组设置不再用卡片包裹。
- 只有可点击的内容列表项（如查词结果）使用卡片；卡片内不得再套卡片。
- 长提示文本必须独立成 `Text`，放在控件下方并允许换行；不要依赖
  `InputDecoration.helperText` 的单行显示，禁止省略号/截断。
- 用户不可变的信息（如应用外部私有目录路径）用 16sp 纯文本展示，
  不使用卡片或输入框。
- 页面左右边距 16；分区之间用 24–32 的留白和分割线区分。

### 页面转场（强制）
- 所有路由（go_router 与 `Navigator.push`）统一使用
  `SlideOverPageTransitionsBuilder` / `RikaiPageRoute`：新页面从右侧滑入并
  覆盖旧页面，旧页面保持原位，不做淡出、缩放或上滑淡入。
- 通过全局 `ThemeData.pageTransitionsTheme` 与 `RikaiPageRoute` 设置，页面
  不得自行定义转场；这样深蓝顶栏导航时不会出现白色残影/白色瑕疵。
- 退出页面为同一动画的反向播放。底部弹层、对话框保持系统自身的弹出方式，
  不属于页面转场。
- 进入 220ms、退出 180ms；不要恢复 300ms 默认值。词条 WebView 在 reverse
  开始时脱离绘制，避免 platform view 在退出瞬间回闪。
- go_router 路由使用 `CustomTransitionPage` 保持相同的 220/180ms 与滑入曲线。

### AppBar（全局统一）
- **所有页面**（主页、阅读、设置、查词、词条、词典、帮助、著作权）统一使用
  深蓝 `#003A99` 背景、白色标题/图标，无底部分割线；状态栏图标为浅色。
- 高 52，标题 16sp/600；图标 20。主页标题居中，其余页面标题左对齐。
- 不使用 elevation/滚动阴影。
- 词条页的 TabBar 位于深蓝顶栏内：白色选中标签与白色指示器，未选中 72% 白。
- 抽屉顶部同为深蓝背景、应用图标与白色文字；**抽屉本体为直角**，不使用圆角。

### 主页功能按钮
- 页面顶部先显示「使用前须知」卡片，再显示初学者友好的「边界说明」卡片：
  OCR 可能漏字/认错，UniDic 按短单位分词、复合词读音不一定完全准确。
- 四个功能按钮放在两张卡片下方的剩余空间中垂直居中；小屏时整体可滚动，
  不得溢出。按钮区不因卡片增加而改变样式。
- 四个全宽实心按钮：拍照识别、输入文本、查词、语料。
- 背景色与顶栏相同：`AppColors.header`（`#003A99`），白色图标与文字。
- 高度 72，圆角 12，图标 28；**图标与文字作为整体居中对齐**。
- 文字 32sp（首版 40sp 的 80%）、行高 1.35，600 字重。
- 不使用副标题；按钮之间的间距为 12。

> **Phase 6 计划备注（未实现）**：`docs/phase6-agent-design.md` 计划把主页改为
> 五个按钮（拍照识别、查句子、查单词、历史记录、词典助手）。当前实现仍是四个；
> 实施 Phase 6 时必须先补充五按钮的小屏布局/token、Agent 对话、严格/宽松选择、
> 来源 chip、Markdown/ruby/声调、provider 设置等规范与自查清单，不能直接硬编码。
> 本节现有四按钮规则在 Phase 6 UI 落地前继续生效。

### 按钮
- 常规主按钮：品牌蓝底、白字、16sp、高 40、圆角 8、水平内边距 16；
  主页四个功能按钮使用 `header` 深蓝与 32sp 居中文字（见上）。
- 常规主按钮不要使用 32sp；大字号只属于主页功能按钮。
- 次按钮：白底、1px 边框、品牌蓝字、同尺寸。
- 文字按钮：品牌蓝字，无底色，最小 40 高。
- 禁用：主色 35% 透明度；不要仅靠灰色文字表达禁用。
- 一屏最多一个主按钮；危险操作使用错误色描边/文字。

### 输入框
- 白底、1px `border`、圆角 8、内容内边距 12；不额外套卡片。
- 聚焦：品牌蓝 1.5px；错误：错误色 1.5px。
- 标签 14sp `textSecondary`；占位符 16sp `textTertiary`；提示/错误 14sp。
- 多行输入保持 16sp；不使用 12sp 正文。
- 长提示放在输入框外，作为独立 14sp 文本；必须换行完整显示。
- 查词页搜索框占位符统一为 **「搜索……」**，不再写“输入日语词条”等长说明。
- 阅读器输入框不填充底色（`filled: false`），工具区保持白色；工具区底部用
  1px `divider` 浅色细线收边。

### 查词词典筛选（搜索页 / 阅读查词弹层）
- 使用可换行的 `FilterChip`，不再横向滚动整行词典全名。
- 第一个选项固定为「全选」；其后按最短唯一前缀显示词典简称，例如“大修”/
  “大辞”/“漢”。仍不唯一时继续增加字符，直到可区分或显示全名。
- 选中 Chip 使用深蓝 `AppColors.header` 背景 + 白字/白图标，不使用浅蓝。
- 提供“多选/单选”模式切换。单选模式下只高亮一个词典，其余 Chip 用 35%
  透明度变暗；多选模式只改变 Chip 自身开关，不暗化其他词典。
- 「全选」在多选模式选择全部；单选模式选择全部后，再次点单个词典恢复单选。

### 卡片
- 白底、12 圆角、1px 边框、无阴影；内边距 12–16。
- 卡片只用于可点击的内容列表项；不要用卡片包裹表单、按钮或整组设置。
- 卡片内标题 16sp；说明 14sp；标题与说明间距 8。
- 卡片可点击时使用 `InkWell`，水波纹颜色品牌蓝低透明度。

### 标签 / Chip
- 高 28，圆角 6，12sp；默认浅灰蓝底，选中蓝50底 + 蓝700字。
- 过滤类 Chip 同时提供文字/勾选状态，不只靠颜色。
- 标签文字超过一行时截断，不换行撑高。

### 列表
- 行最小高度 56，水平边距 16，垂直内边距 4–8。
- 主文字 16sp，副文字 **14sp**；尾部图标 20。
- 长副标题使用独立可换行布局，不使用会截断的单行 ListTile subtitle。

### 底部弹层 / 对话框
- 底部弹层：白底、顶部 16 圆角、拖动条 4×32、内容内边距 16。
- 对话框：白底、12 圆角、无阴影、标题 16sp、正文 16sp、按钮右对齐。
- 弹层默认高度不超过屏幕 80%；内容可滚动。

### Tab
- 标签 16sp；位于深蓝 AppBar 内时：选中白色 + 白色指示器，
  未选中 72% 白色；位于白色内容区时仍使用品牌蓝。
- 多于 4 个 Tab 时允许横向滚动。

### 进度 / 开关 / 滑块
- 进度色品牌蓝，轨道蓝100（或浅灰蓝）。
- 开关选中品牌蓝；滑块激活品牌蓝。
- 加载状态必须有文字说明（例如“正在加载分词功能…”），不能只有转圈；
  对用户可见的加载文案避免直接出现 UniDic/MDict 等技术名。

### 拍照识别 / 照片集
- 相机页：顶栏保持深蓝；相机预览铺满顶栏以下区域，`BoxFit.cover`；底部控制区
  使用 `cameraScrim` 半透明遮罩，快门居中，左侧“导入照片”，右侧“照片集”
  （数量角标）。相机不可用/权限被拒时，隐藏快门但保留“去授权/重试”、
  “从相册导入”和“照片集（N）”三个入口，不能让后两者消失。
- 拍照/导入成功后，在画面中央显示短时半透明提示“照片已加入照片集，请在
  照片集中查看”；不要让反馈只体现在角落数字上。
- 照片集：照片区 `BoxFit.contain`；下边缘提供**纯白色单色**拖拽指示条
  （不得再加深色胶囊/描边），向下拖动放大照片区、向上缩小（默认 250、
  最小 120，保留结果与操作区空间）；拖拽热区 40dp，直接处理 pointer 事件，
  不得使用有 slop 延迟的拖拽识别器，必须从手指移动第一像素起跟手。
  点击照片打开黑底全屏查看器，支持双指缩放与拖动（参考系统画册）。
- 照片集不再提供“分析句子”按钮。配置 UniDic 后，识别结果自动按文本阅读页
  的 TokenChip 方式显示并可直接点词查词；未配置或分词失败时显示 OCR 原文。
- 分词失败提示使用**红色横幅叠放在照片顶部**（标题栏下方），包含原因和白字
  “重试”；不得占用/排挤 OCR 结果区域。未配置 UniDic 的说明可留在结果区。
- 照片右下角的复制按钮文案统一为**「复制文本」**（`PhotoCopyButton` 默认值），
  样式为深蓝 `header` 长条按钮（白字白图标），有 OCR 文本后可用；标题栏只保留
  字号/注音菜单和“多选”。语料预览卡片右下角的复制按钮仍用较短的「复制」。
- 字号与注音使用与文本阅读页相同的 `ReaderOptionsMenu`（16/20/24/28、显示注音）；
  不得单独发明第二套字号控件。
- 识别模式为自动/横向/竖向；安装 MangaOCR 后竖向可用，未安装时选择竖向应在
  结果区给出中文下载提示。模式保存在拍摄会话中，离开再打开照片集不得重置为自动。
- 识别方向、模型设置、页码导航三组控件贴近页面底部；页码箭头中心必须与
  画面左下/右下角 52dp 圆形删除/保存按钮的中心同高。Phase 4.5 在底部
  “模型设置”旁增加“旋转”文本按钮（顺时针 90° 并重新识别），仍使用标准
  `TextButton.icon`，不新增硬编码颜色/字号；标题栏仍只保留字号/注音菜单和
  “多选”。
- “保存到语料库”和“删除”使用 52dp 悬浮圆形图标，固定在**整个画面**
  左下/右下角（不是照片区角落）；删除为错误色，保存为深蓝 `header` + 白图标
  （不要用白底，白底在照片页面上对比度不足）。两者尺寸、图标大小一致，
  不得重复放文字按钮。
- 多选页：网格缩略图使用 `BoxFit.contain`，OCR 预览字号至少
  `AppTypography.ocrPreview`（20sp），复选框/已选数量；删除/保存沿用
  与单张页相同的 52dp 圆形图标和语义，批量保存需二次确认；不重复放
  “全选”以外的多选入口。
- 识别结果按“照片 + 模式 + 模型指纹”缓存，模式为会话级；从模型设置、多选页
  或其它页面返回时，若指纹/模式未变必须直接显示缓存，不得重新 OCR。多选页
  进入时只补识别没有缓存的照片。切换照片/模式才重新识别；同一时间只有一个
  识别任务；识别中禁止保存。

### OCR 模型页 / 导入页
- 模型页不展示内部开发路径或环境变量；首句为“OCR 模型需单独下载，下载完成后
  可离线使用。”模型目录用 16sp `SelectableText` 展示，提供“更改目录”；
  目录切换默认迁移现有模型，也可仅切换；显示已安装占用空间；目录不可用时
  显示错误和重新选择入口。
- 模型长提示统一 14sp、完整换行；加载态必须有文字（“正在检查模型…”）。
- 模型页/词典导入页使用白底扁平布局，不把输入框、按钮和提示包在 Card 中；
  模型下载/迁移显示进度，支持取消下载；本地导入完成后清理 file_picker 缓存。
- MangaOCR 模型许可未声明：下载前必须弹出确认对话框，说明只从上游下载、不随
  应用分发、不上传图片或文本；取消后不得开始下载。
- MDict 导入页：文件夹输入框 hint 为“请选择词典所在文件夹”，浏览后递归
  扫描，列出可导入/已存在/不支持；扫描结果尾部不显示 `MDD`/`CSS` 等英文
  缩写与数量；底部只有一个“导入所选（N）”主按钮。导入结束（含部分失败）
  直接返回词典管理页，不弹出结果对话框；仅用非阻塞 SnackBar 报告失败数量。
  词典管理的资源标签使用“资源/样式/无资源”，不使用 MDD/CSS 缩写。
  扫描/导入进度与错误一律不显示 `Instance of ...`、异常类名或原始英文；
  损坏项只显示“不支持”。
  UniDic 页使用相同字段/浏览/校验顺序和 14sp 说明。

### 语料列表与语料详情
- 语料列表和语料详情标题栏右上角都提供 `ReaderOptionsMenu`（显示注音 +
  字号 16/20/24/28）；列表 OCR 正文和详情 OCR/分词都随字号设置变化。
- 语料列表改为与照片集多选页一致的**两列紧凑卡片**：照片 `BoxFit.contain`
  完整展示，OCR 结果最多 3 行省略，不再把整页 OCR 文本全部铺开；照片右上角
  叠放错误色圆形删除按钮（`corpusAction` 44dp），卡片右下角放「复制」，
  日期只在卡片底部用 14sp 次要色显示。
- 点击语料进入「语料」详情页，视觉与照片集一致：可调整高度的照片区、点击
  全屏缩放、照片右下角「复制文本」、分词结果（本地 UniDic/MDict，全离线）。
  详情页**不再重复显示 OCR 原文和日期**。
- 详情页与照片集的区别：无“多选”、无识别方向、无模型设置跳转、无保存按钮；
  页码箭头在语料条目之间切换；标题栏左对齐文字「语料」；画面左下角保留
  错误色圆形删除按钮（二次确认）。不得出现网络资源。
- 照片集多选卡片的 Checkbox 不再使用黑色圆形底衬；未选中透明、选中深蓝。

### 阅读器 TokenChip
- 内容词：蓝50背景、蓝700文字、6 圆角、内边距 4×2。
- 功能词：透明背景、`textPrimary`（近黑），**不得使用灰色**。
- 标点/空白：无背景、无点击、无注音、`textPrimary`。
- 振假名：主字号的 55%，品牌蓝 `primary`，**不得使用灰色**。
- 阅读器内不使用 `textSecondary`/`textTertiary` 渲染分词结果；用品牌蓝、
  近黑与字重区分层级，减少灰色与色块带来的视觉刺激。
- 点击目标至少 40 高；Wrap 间距 2/8。

### 空状态 / 错误状态
- 居中；图标 40–48，标题 24sp（页面级）或 16sp（局部），说明 14sp。
- 必须给出下一步操作（重试 / 打开设置 / 添加词典），不能只有错误文字。

### 查词结果
- 点击单条结果只进入该词条页面，不混合显示其他搜索结果。
- 同一词典结果 ≥2 条时，在该词典结果列表最前面显示“查看全部（N 条）”；
  点击后只显示该词典下该词的全部词条。
- 多词典默认每本最多显示的词条数由“阅读显示 → 每词典词条上限”控制，
  默认无限制。
- **字号层级**：词典名称与条目数均为 16sp，且使用同一颜色；
  “查看全部”为 16sp；词条标题为 **24sp**（原 16sp 的 1.5 倍）；
  词条摘要为 14sp。不得把它们降回 12sp。
- 阅读页弹出的查词列表顶部**不放置关闭叉**：下滑、上滑或点击遮罩即可关闭，
  关闭叉属于冗余操作。
- 若读音与文字形式完全相同（例如 `ありがとう` 与 `ありがとう`），
  只显示黑色词形，不显示蓝色读音行；仅当读音不同且非空时显示品牌蓝读音。

### 长文页面（帮助 / 著作权）
- 白底纯文本，不使用 Card/ListTile 堆叠。
- 栏目标题 18sp/600；正文 16sp、行高 1.7；栏间使用 Divider 分隔。
- 不截断、不省略；路径/许可证名称可换行。
- 许可证按钮直接放在页面底部，不套卡片。

## 9. 字体获取

字体不在仓库中。构建前：

1. 从华为 HarmonyOS 设计资源下载 HarmonyOS Sans（SC Regular）。
2. 放置为 `assets/fonts/HarmonyOS_Sans_SC_Regular.ttf`。
3. 运行 `flutter pub get` 与构建；缺失时构建会报 asset 错误。

详见 `assets/fonts/README.md`。字体由使用者自行下载，项目不再分发。
