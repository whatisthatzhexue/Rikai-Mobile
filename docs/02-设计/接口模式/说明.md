# 接口模式（JSON Schema）说明

> 状态：当前权威（接口模式说明）｜最后同步：2026-11-11

本目录保存 Agent 内部 DTO/存储契约的 12 份 `*.v1.schema.json`。它们是**文档契约**，
不是运行时输入格式，也不被打包进 APK；运行时和测试都不读取这些文件。

## 1. 用途

| 文件 | 用途 | 状态 |
|---|---|---|
| `input.v1.schema.json` | Agent 输入/证据请求结构 | 当前 |
| `evidence.v1.schema.json` | 证据包结构 | 当前 |
| `analysis.v1.schema.json` | 分析结果内部 DTO/存储结构 | 当前；模型响应不是 JSON |
| `coverage.v1.schema.json` | F7 覆盖审查结果 | 当前 |
| `quote.v1.schema.json` | 原文引用/定位 | 当前 |
| `dictionary-profile.v1.schema.json` | 词典熟悉档案 | 当前 |
| `pitch.v1.schema.json` | UniDic 声调 | 当前 |
| `annotation-rules.v1.schema.json` | 注音/标注安全 DSL | 当前 |
| `history-entry.v1.schema.json` | 历史条目 | 当前 |
| `history-result.v1.schema.json` | 历史结果 | 当前 |
| `word-list.v1.schema.json` | 词表包格式 | 未来；无运行时导入 |
| `tool-result.v1.schema.json` | 工具结果 | 未来；当前模型无工具 |

## 2. 重要边界

- `analysis.v1` 明确：模型响应是**方括号标签纯文本**，由
  `lib/services/agent/analysis_tag_parser.dart` 解析；JSON Schema 只描述内部 DTO。
- `tool-result.v1` 仅作未来 tool loop 参考；当前 `lib/services/agent/tools/` 已删除，
  模型请求不携带 tools。
- `word-list.v1` 没有代码常量；词表 UI/导入/非日语 tokenizer 尚未实现，不能写成已支持。

## 3. 漂移风险

Dart 常量与 JSON 手工副本可能不同步。M1 可加 contract test 对比 `required`/limits，
或从 Dart 定义生成 JSON；在那之前，修改字段时必须同时更新本目录与
`lib/core/models/agent/`。

JSON Schema 文件名保留英文技术命名，是本仓库“中文文件名”规则的登记例外。
