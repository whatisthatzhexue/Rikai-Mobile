1. `01-规范/项目规则.md`：MUST/MUST NOT 规则的单一来源（`R-*`）。

5. `02-设计/助手/助手契约.md` + `02-设计/接口模式/agent/`：Agent 字段/错误码/状态机。

冲突时以更高层级为准，并修正低层级摘要。

## 4. 命名、状态与版本规范

### 3.1 命名

- 文件夹/文件名：中文、无空格、无全角括号/标点；编号/日期用 `-`。
- 例外：`README.md`、`CLAUDE.md`、`NOTICE`、`THIRD_PARTY_NOTICES.md`、
  JSON Schema（`*.v1.schema.json`）、样本时间戳、许可证文本。
- 新文档必须中文；存量英文正文的翻译按 M1 批次 E 分批进行，只改语言不改数值/结论。

### 3.2 状态横幅

每份当前文档标题下必须有且只有一条状态横幅：

```text
> 状态：当前权威（规则/数据/设计/进度）｜最后同步：YYYY-MM-DD
> 状态：历史快照（保留当时值，不代表当前实现）
> 状态：已废弃（由 … 取代）
```

历史文档和样本可保留原文；历史文档需有“历史快照”横幅。

### 3.3 版本词汇表

| 维度 | 唯一写法 | 禁止/别名 | 示例 |
|---|---|---|---|
| 产品阶段 | 中文正文 `阶段 N`；英文文档 `Phase N` | `Phase` 与工作包混写 | `阶段 6`、`Phase 6`（英文） |
| 阶段 6/7 工作包 | `P6.x`、`P7.x`、`P6.7-1` | `Phase 6.7`、`阶段 6.7` | `P6.7-2`、`P7.0` |
| 设备反馈波次 | 仅设备反馈文档用 `Wave N`；中文其他文档 `反馈波次 N`；英文 `feedback wave N` | 其他文档裸写 `Wave N` | `反馈波次 4` |
| 优先级 | `优先级 高/中/低` 或 `批次 A/B/C` | `P0/P1/P2` | `优先级 高` |
| 维护阶段 | `M-1/M0/M1` | `Phase -1/0/1` | `M0 文档结构` |
| Agent 重构 | `R1a–R4` | `Phase 1a–4` | `R1a 档案编译器` |
| 范围 | 完整写 `P6.8（完整）`/`P7（完整）`；当前写 `P6.8-lite`/`P7-lite` | 裸写 `P6.8`/`P7` 指当前实施 | `P6.8-lite` |

`Phase` 只作英文别名，等价于中文 `阶段`；`P6.x`/`P7.x` 只表示工作包，不是产品阶段。

## 6. 维护命令

```text
dart tool/check_docs.dart              # 链接/旧路径/登记/命名/横幅/版本标签
dart tool/verify.dart                   # check_docs + app analyze + app test
dart tool/verify.dart --build           # 再加 app debug APK
```

Flutter。

Agent、真机视觉等验收项仍以 `03-进度/阶段6实现状态.md` 和
`03-进度/设备反馈-2026-10-31.md` 为准。
